## camp tag rm

Remove tags from a camp

### Synopsis

Remove one or more tags from a camp.

Removing a tag the camp does not carry is a no-op for that tag.

```
camp tag rm <camp> <tag>... [flags]
```

### Examples

```
  camp tag rm obey-campaign q3-2026
```
